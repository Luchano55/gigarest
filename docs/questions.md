# Вопросы к Роману

## Ответы от 24.10.2026

1. **Второй монитор** стоит **справа** от основного. Масштаб 100%, может быть до 150%.
   → Плитки и перенос окон рассчитываем на масштаб второго монитора 100–150% (D-WINDOWS).
2. **Рабочие программы** выбираются в настройках, а не жёстким списком.
   → Так и задумано (ТЗ, раздел 4: первый запуск показывает открытые программы, Роман расставляет действия).
   Завершение «лишних» процессов для ускорения системы — позже, отдельным этапом (D-BOOST).
3. **Профиль браузера не меняем.** Браузер может быть одной из 4 плиток второго монитора.
   → Отдельную папку «Chrome — работа» не делаем. Chrome целиком либо уходит на второй монитор, либо закрывается (D-CLOSE, D-CHROME).
4. **Кнопки** решим в процессе, возможно — голосовая команда.
   → Пока по умолчанию Ctrl+Alt+Home, меняется в настройках. Голос — идея на потом (D-VOICE).
5. **Гарнитура одна.**
   → Переключение устройства вывода не нужно, из ближайших этапов убрано (D-AUDIO).
6. **Музыка — Яндекс Музыка**, установлена.
   → Четвёртая плитка по умолчанию — Яндекс Музыка. Проверить на прототипе плиток (D-THUMBS).
7. **Возврат к работе — гибридно, настраивается.**
   → Кнопка и горячая клавиша всегда; плюс расписание в настройках (D-SCHEDULE).

## Открытые

1. **Разрешение второго монитора** (например, 2560×1440 или 1920×1080)? Нужно для макета плиток.
2. **Рабочий и личный браузер — это один Chrome с двумя профилями или разные браузеры?**
   Если один Chrome — его окна можно только все вместе: либо на плитку, либо закрыть. Тогда рабочие вкладки останутся видны на плитке.
3. **Расписание:** какое по умолчанию — например, будни 9:00 возврат к работе? Нужно ли и обратное — автоматически переходить в отдых вечером?
4. **Остальные рабочие программы:** кроме Битрикс24, Outlook и Яндекс Диска — что ещё обычно открыто вечером? Не обязательно сейчас: при первом запуске программа сама покажет список.
