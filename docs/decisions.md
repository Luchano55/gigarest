# Принятые решения

Проверено исследованием 24.10.2026. Пункты с (?) — не подтверждены источниками, проверить прототипом на ПК Романа.

## D-UI. Интерфейс — WinUI 3 + Win2D, не WPF
- **Почему не WPF.** У WPF известные рывки на 144 Гц и VRR. Задача dotnet/wpf#2294 открыта, в 2024 году мейнтейнер ответил «Sorry no». Фактический потолок около 60 кадров/с, `DesiredFrameRate` частоту только понижает. `MediaElement` плохо справляется с 4K HEVC и с петлёй.
- **Почему WinUI 3.** Анимации Composition (Ken Burns, прозрачность, размытие) выполняет системный композитор с частотой монитора. Частицы — Win2D `CanvasAnimatedControl` / `CanvasSpriteBatch`.
- **Запасной вариант** — сцена в WebView2 (HTML/canvas): плавно и быстро в разработке, но тяжелее по памяти.
- **Следствие:** приложение собирается только на Windows (в CI). Логика — в `GigaRest.Core` (net8.0), она тестируется на Linux.
- Источники: https://github.com/dotnet/wpf/issues/2294

## D-FPS. Частота кадров
- Движение считать от реального времени кадра (delta-time), а не по счётчику кадров.
- Спокойная сцена по умолчанию ограничена ~82 кадрами/с, настраивается.
- Цель — нагрузка на видеокарту в спокойной сцене не выше 10%.

## D-VIDEO. Видео-сцены
- **Сделано (25.10.2026):** `VideoLoop` — два `MediaPlayer`, за ~1 с до конца второй начинает сначала и проступает поверх (перекрёстный переход), без звука. Короче 3 с — обычный `IsLoopingEnabled`.
- **Эффекты пока на анимациях XAML/композитора** (эллипсы с мягким градиентом, текстура тумана), не Win2D: движение считает системный композитор с частотой монитора, а сборка не зависит от лишнего пакета. Если на 4K 165 Гц будет тяжело — переносим частицы в Win2D.
- Видео играет WinRT `MediaPlayer` в режиме frame server (`IsVideoFrameServerEnabled`, `CopyFrameToVideoSurface` → Win2D). Декодирование аппаратное.
- Для HEVC нужно расширение «HEVC Video Extensions».
- Бесшовность `IsLoopingEnabled` не документирована (?). Если на стыке будет шов — два плеера с перекрёстным переходом. Ещё один запасной вариант — libmpv.
- LibVLCSharp не брать: чёрные вспышки на 4K HEVC (LibVLCSharp#421).
- Совет пользователю: ролики сцен без звука, с ключевым кадром в начале. Перекодировать можно через DropWheel или ffmpeg.

## D-PAUSE. Пауза, когда идёт игра
- Раз в 1–2 с опрашивать `SHQueryUserNotificationState`: значения `QUNS_RUNNING_D3D_FULL_SCREEN`, `QUNS_BUSY`, `QUNS_PRESENTATION_MODE` означают паузу.
- Дополнительно проверять, что активное окно не наше и закрывает весь монитор (окно без рамки), как в Chromium `fullscreen_win.cc`.
- Если игру запустили из GigaRest — пауза сразу.
- На паузе останавливать рендер и освобождать декодер.

## D-THUMBS. Живые плитки — DWM Thumbnails
- **API:** `DwmRegisterThumbnail(наше окно, окно программы)` → `DwmUpdateThumbnailProperties` → `DwmUnregisterThumbnail`. Картинку собирает сам DWM на видеокарте, наш процесс почти не нагружается.
- **Миниатюра рисуется поверх содержимого нашего окна.** Подписи и бейджи — рядом с прямоугольником миниатюры, не поверх.
- **Свёрнутое окно живьём не показывается** — DWM держит последний кадр. Поэтому окна плиток «паркуются» развёрнутыми под экраном плиток.
- **Chromium и Electron** (Chrome, Claude) перестают рисовать полностью перекрытое окно (native window occlusion). Тогда плитка показывает последний кадр с подписью.
  - Для своего Chrome можно передать флаг `--disable-features=CalculateNativeWinOcclusion` (?).
- **Порядок:** этап 4 начинается с прототипа.
- **Первая версия (25.10.2026):** окно плиток WinUI на весь второй монитор, `DwmRegisterThumbnail` в прямоугольники плиток (пропорции окна сохраняются). Окна программ развёрнуты под ним; «Свернуть» ловится `SetWinEventHook(EVENT_SYSTEM_MINIMIZESTART)` — окно разворачивается обратно без активации, плитки — сверху; Ctrl+Alt+Пробел — то же. Окно плиток — WS_EX_LAYERED с альфой 254: Chromium/Firefox не считают его непрозрачным и не перестают рисовать окна под ним (?, проверить на ПК Романа; если окно плиток окажется чёрным — убрать).
- **Esc** для возврата в плитки не берём (нужен самим программам); Роман спрашивал — предложено двойное Esc по желанию.
- Источники: https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmregisterthumbnail , https://chromium.googlesource.com/chromium/src/+/master/docs/windows_native_window_occlusion_tracking.md

## D-WINDOWS. Перенос окон
- **Сначала сохранить положение:** `GetWindowPlacement` и `GetWindowRect`.
- **Перенос:** `ShowWindow(SW_RESTORE)` → `SetWindowPos` в рабочую область второго монитора → `ShowWindow(SW_MAXIMIZE)`. Разворачивать **после** переноса: окно само подстроится под DPI монитора.
- Приложение — PerMonitorV2. Второй монитор у Романа стоит справа, масштаб 100–150%: координаты плиток считать в пикселях монитора с учётом его DPI, в тестах ядра — оба масштаба.
- Сворачивание и закрытие чужих окон ловить через `SetWinEventHook` (`EVENT_SYSTEM_MINIMIZESTART/END`, `EVENT_OBJECT_DESTROY`) с флагами `WINEVENT_OUTOFCONTEXT | SKIPOWNPROCESS`. Делегат держать в поле, работу передавать в UI-поток.
- **Программы из Store:** окно принадлежит `ApplicationFrameHost.exe`. Окна с правами администратора недоступны (UIPI) — предупреждать.
- Предупреждение Рэймонда Чена: управлять чужими окнами рискованно. Поэтому всё делаем с проверкой результата. https://devblogs.microsoft.com/oldnewthing/20210118-00/?p=104725

## D-CLOSE. Вежливое закрытие
- **Исключение по решению Романа (25.10.2026):** галочка «завершать принудительно, даже если есть несохранённое» для конкретной программы (ShareX с несохранёнными скриншотами). Сначала WM_CLOSE, через 5 с — завершение всех процессов программы, вопрос «Сохранить?» не ждём и вперёд не выводим. Без галочки правило прежнее: при открытом вопросе — никогда. В итоге у программы, которая не закрылась, есть кнопка «Завершить принудительно — несохранённое пропадёт» (ставит галочку на будущее).
- **Реализовано на этапе 1** (`CloseOrchestrator`): все программы закрываются параллельно; вопрос — видимый диалог `#32770` с владельцем или отключённое главное окно; после вопроса программа не завершается никогда, даже с галочкой.
- Для программ без правила окно исчезло, а процесс жив (Outlook сохраняет почту) — ждём до общего таймаута; с галочкой — завершаем через 10 с.
- **Закрытие:** `EnumWindows` → все видимые окна процесса верхнего уровня без владельца → `PostMessage(WM_CLOSE)`.
- **Вопрос «Сохранить?»:** признак — главное окно отключено, есть всплывающее окно `#32770` / `GW_ENABLEDPOPUP`. Тогда статус «программа спрашивает», окно — вперёд, ждём.
- **Командная строка для перезапуска** — `NtQueryInformationProcess(ProcessCommandLineInformation)` (Windows 8.1+, без WMI и без прав администратора). Разбор на аргументы — по правилам `CommandLineToArgvW`, запуск — через `ArgumentList`. У Chrome и Electron брать корневой процесс без `--type=`.
- **Дерево процессов** — `CreateToolhelp32Snapshot`; учитывать время старта, чтобы не перепутать переиспользованный PID.
- **Chrome — без отдельной папки данных** (решение Романа, 24.10.2026, см. D-CHROME).

## D-OLED. Защита OLED
- **Сдвиги:** статичные элементы смещаются на ±10–30 px каждые 1–3 мин.
- **Яркость:** текст 85–90% яркости. Через 15 мин без ввода — затемнение до 10%, через 60 мин — предложить выключить экран (`SC_MONITORPOWER`).
- **Курсор и панель задач** прячутся.
- **Не мешать уходу экрана в сон:** `ES_DISPLAY_REQUIRED` бесконечно не держать.
- Pixel refresh монитора не мешать.
- Источник: https://us.msi.com/blog/how-msi-oled-care-prevents-oled-from-burn-in

## D-SCHEDULE. Возврат к работе — кнопкой и по расписанию (24.10.2026)
- Режим «гибридно»: кнопка, горячая клавиша и, по настройке, расписание (дни недели + время).
- Логика расписания — в `GigaRest.Core` (чистая функция «когда следующее срабатывание»), под тестами, включая переход на летнее/зимнее время.
- **Безопасность:** если в момент срабатывания идёт игра на весь экран или Роман активно что-то делает, не переключаем молча, а показываем тихое предложение «Пора за работу · Вернуться / Через 15 мин».
- Если ПК спал в момент срабатывания — предложение показывается после пробуждения.
- **Сделано на этапе 1**: `ReturnSchedule` в ядре (тесты), проверка раз в 30 с с запоминанием прошлой проверки — так ловится и пробуждение ПК; окно «Настройки». Во время игры/фильма на весь экран/презентации/блокировки (`SHQueryUserNotificationState`) предложения откладываются на 15 минут.
- **Вечернее предложение отдыха** (Роман, 24.10.2026: «нужно, но мягкое») — тот же `DaySchedule`, но только уведомление у значка в трее (щелчок открывает окно перехода). Одно за вечер, без повторов.

## D-BOOST. Фоновые процессы — завершать на время отдыха (25.10.2026)
- Роман: «если глушим процессы, важно иметь возможность их запустить, чтобы комп не терял».
- **Сделано** (`BackgroundScanner`): кандидаты — корневые процессы нашего сеанса без окон, не помощники открытых программ, не от администратора и с понятной командой запуска (exe + аргументы). Чего не сможем запустить обратно — не показываем.
- **Никогда не трогаем:** папку Windows, системный список, драйверы и «железо» (видео, звук, мышь/клавиатура, ноутбучные утилиты), антивирусы, VPN — по имени и пути.
- Выбор «завершать в отдыхе» = разрешение завершать (окон у процесса нет, ждать нечего — завершаем сразу). При возврате — запуск той же командой; что не запустилось — в итоге «откройте вручную».
- То, что GigaRest сам перезапустил при возврате, в следующий раз снова в списке (его окно и он сам — не «родитель-программа»).

## D-GAMES. Библиотеки игр (26.10.2026)
- Steam: папка из `HKCU\Software\Valve\Steam\SteamPath`, список библиотек — `steamapps\libraryfolders.vdf`, игры — `appmanifest_*.acf` (`appid`, `name`, `StateFlags` с битом 4 «установлена», `LastPlayed` — время Unix). Запуск — `steam://rungameid/<appid>`. Служебные пакеты (Steamworks Redistributables, Proton, Steam Linux Runtime) не показываем.
- Epic: `%ProgramData%\Epic\EpicGamesLauncher\Data\Manifests\*.item` (JSON: `DisplayName`, `AppName`, `CatalogNamespace`, `CatalogItemId`, `AppCategories`, `bIsIncompleteInstall`). Запуск — `com.epicgames.launcher://apps/<ns>%3A<item>%3A<app>?action=launch&silent=true`. Время последней игры Epic не хранит — берём из своих запусков (`GamesPlayed` в настройках).
- GOG: `HKLM\SOFTWARE\WOW6432Node\GOG.com\Games\<id>` (`gameName`, `exe`, `workingDir`; `dependsOn` — дополнение, пропускаем). Чтение HKLM не требует прав администратора. Запуск — exe напрямую.
- Battle.net: список в `product.db` закрытый (protobuf), поэтому берём «Установка и удаление программ» (Uninstall в HKLM/HKCU): `Publisher` = Blizzard Entertainment, код продукта из `--uid=` в `UninstallString`. Запуск — `Battle.net.exe --exec="launch <код>"` по таблице кодов (`BattleNet.cs`); код неизвестен — просто открываем Battle.net (ТЗ, раздел 8).

## D-MINIMIZE. «Свернуть» у окна с плитки (26.10.2026)
- По событию сворачивания экран плиток сразу становится «поверх всех» (системная анимация сворачивания уходит под него), копия окна, которая всё время открытия стоит на весь экран под окном, уменьшается в плитку; через 300 мс окно тихо разворачивается под плитками, и экран плиток снова обычный.
- Дополнительно пробуем выключить системную анимацию у окон плиток (`DWMWA_TRANSITIONS_FORCEDISABLED`); Windows может не разрешить это для чужого окна — тогда код ошибки в журнале, наша анимация всё равно поверх. При возврате к работе включаем обратно.

## D-DND, реализация (27.10.2026)
- Стратегия 1 — системное состояние оболочки «тихие часы» (WNF `WNF_SHEL_QUIETHOURS_ACTIVE_PROFILE_CHANGED`, `ntdll!NtUpdateWnfStateData`): профиль 1 «только приоритетные». Без прав администратора. Проверка — чтение состояния обратно (`NtQueryWnfStateData`) через 300 мс; итог пишется в журнал.
- Почему не перезапуск `WpnUserService_*`: для остановки службы обычно нужны права администратора, а их не просим.
- Стратегия 2 — если Windows режим не приняла: надпись «включить „Не беспокоить“» на «Тихом» экране открывает `ms-settings:notifications`, плюс одно уведомление у значка.
- Прежнее значение — в `%AppData%\GigaRest\dnd-before.txt`; возвращаем при выходе из отдыха (и при выходе из программы), файл удаляем.
- Не подтверждено на Windows 11 24H2 — проверить у Романа (docs/manual-tests.md).

## D-WATCH и D-LISTEN (27.10.2026)
- «Слушать» — `GlobalSystemMediaTransportControlsSessionManager.GetCurrentSession()`, кнопки — `TrySkipPreviousAsync`, `TryTogglePlayPauseAsync`, `TrySkipNextAsync` (как медиаклавиши).
- «Смотреть» — файлы видео в папке с фильмами (по умолчанию «Видео»), до двух уровней вложенности, без скрытых и системных, без «sample» и файлов меньше 5 МБ. Открытие — `UseShellExecute`, то есть плеером по умолчанию. «Смотреть позже» — ссылка `youtube.com/playlist?list=WL` в браузере по умолчанию: GigaRest сам в сеть не ходит.

## D-INSTALL. Установщик (27.10.2026)
- Inno Setup 6, как в DropWheel: `packaging/installer/GigaRest.iss`, только для текущего пользователя (`PrivilegesRequired=lowest`), папка `%LocalAppData%\Programs\GigaRest` (доступна на запись — самообновление работает), ярлык в меню «Пуск», запись в «Установленных приложениях» (HKCU).
- Перед установкой и при удалении — `GigaRest.exe --exit`: просит работающую копию выйти тем же способом, что новая версия просит старую (событие `Local\GigaRest.Quit`), и ждёт до 15 с. При выходе отдых возвращает «Не беспокоить».
- CI собирает `GigaRest-Setup.exe`, ставит его тихо, проверяет exe, ярлык и запись удаления, `--exit` без запущенной программы (код 0), удаляет и проверяет, что папка очистилась. Выпуск `dev-build` — с постоянной ссылкой на установщик.

## D-LAUNCH. Steam и Battle.net «внутри» GigaRest — нельзя, поэтому прячем (27.10.2026)
- Встроить окно чужой программы в своё (SetParent другого процесса) Microsoft не поддерживает: ломаются ввод, масштаб, полноэкранный режим игры. Steam и Battle.net — браузерные окна (CEF/Chromium), с ними это особенно ненадёжно.
- Steam: запуск `steam.exe -silent -applaunch <appid>` — игра стартует, главное окно Steam не открывается.
- Battle.net: `--exec="launch <код>"` своего тихого режима не имеет; 90 с после запуска сворачиваем (SW_SHOWMINNOACTIVE) только главное окно с заголовком ровно «Battle.net» / «Steam». Окна-вопросы с другими заголовками не трогаем, ничего не закрываем.
- Battle.net: код продукта в «Удалении программ» бывает с языком (`wow_ruru`) — язык отрезаем; «когда играли» — `Games.<код>.LastActioned` из `%AppData%\Battle.net\Battle.net.config`.

## D-PLAYER. Встроенный плеер (27.10.2026)
- `MediaPlayerElement` + системный `MediaPlayer` (аппаратное декодирование, тот же, что для видео-сцен, D-VIDEO) на весь «Тихий» экран; сцена за ним останавливается. Форматы — что умеет Windows (MP4/H.264, MKV; HEVC — с расширением из Microsoft Store). Не открылось — файл открывается плеером Windows по умолчанию.
- Где остановились — в настройках (`FilmsPosition`); начало (< 1 мин) и конец (последние 3 %, до 5 мин) не запоминаем.
- Свой плеер — запуск exe с путём к фильму через `ArgumentList`. Плееры находим по ярлыкам меню «Пуск».

## D-RELEASE, стабильные версии (27.10.2026)
- Как в DropWheel: тег `vX.Y.Z` (или ручной запуск сборки с галочкой «release») → стабильная версия X.Y.Z, обычный релиз «GigaRest X.Y.Z» с описанием из раздела `## X.Y.Z` в `docs/CHANGELOG.md` (`build/release-notes.ps1`). GitHub считает его последним: постоянные ссылки `releases/latest/download/GigaRest-Setup.exe` и `…/GigaRest-win-x64.zip`.
- Остальные сборки из `main` и `claude/*` — тестовые `X.Y.Z-dev.<номер>` в выпуске `dev-build`. Выпуск больше не удаляется и не создаётся заново: файлы заменяются на месте, ссылка не пропадает во время сборки.
- Канал обновлений в программе: «Как при установке» (по версии: `-dev` — тестовые), «Стабильные версии» (`releases/latest/download/version.json`), «Тестовые сборки» (`releases/download/dev-build/version.json`). Номер сборки — номер запуска CI, сравнение то же.

## D-WEBMUSIC. Яндекс Музыка и YouTube внутри GigaRest (27.10.2026)
- Окно приложения Яндекс Музыки встроить нельзя (чужой процесс, см. D-LAUNCH). Встраиваем сайт `music.yandex.ru` через WebView2 (входит в Windows 10/11 как Microsoft Edge WebView2 Runtime) — по просьбе Романа, чтобы выбирать песни на «Тихом» экране.
- Свой профиль браузера: `%LocalAppData%\GigaRest\WebView2` — вход запоминается; установщик стирает его при удалении. Окна «в новой вкладке» и вход открываются в том же месте (`NewWindowRequested` → `Navigate`).
- «Свернуть» прячет панель, страница живёт — музыка играет; её видно в системных медиа-сеансах, поэтому кнопки «Слушать» работают. «Закрыть» и возврат к работе закрывают страницу.
- Сеть: страница грузится только по щелчку человека; сам GigaRest по-прежнему ходит в сеть только за обновлениями.
- YouTube — та же панель (свой экземпляр, музыка при этом играет дальше): главная или `youtube.com/feed/history`, где после загрузки скрипт открывает верхний ролик истории — последний просмотренный. Не вошли в аккаунт — остаётся страница истории с кнопкой входа.

## D-LIBRARY. Библиотека игр (27.10.2026)
- Встраивать окна Steam и Battle.net не стали (D-LAUNCH: чужие окна через SetParent зависают вместе, ломают масштаб и полноэкранные игры). Вместо этого — своя библиотека из списков магазинов: только установленные игры.
- GigaRest не ищет exe по диску (медленно, много лишнего: установщики, утилиты). Игры без магазина Роман добавляет сам: «+ Добавить игру…» → exe; название — по папке игры. Хранится в настройках (`CustomGames`).
- Свои обложки — папка «Изображения\GigaRest\Обложки», имя файла = название игры (сравнение без регистра, пробелов, знаков, «ё» = «е»); «… шапка» — широкая картинка. Из интернета обложки не качаем.

## D-SOUNDS. Звуки природы (27.10.2026)
- Не записи (чужие записи в публичный репозиторий не кладём, а свои сделать нельзя), а синтез в программе: розовый и «бурый» шум, биквадратные фильтры (формулы RBJ), случайные события — капли (дождь), щелчки (костёр), волны с периодом 7–11 с (море), порывы (ветер). Кольцо 40 с, концы сведены за 3 с — по кругу без шва; громкость выравнивается по средней силе звука, пики мягко скругляются (tanh).
- Проигрывание — системный MediaPlayer по кругу из памяти; в медиа-сеансы Windows не попадает (`CommandManager.IsEnabled = false`), чтобы «Слушать» по-прежнему управлял музыкой.
- По решению Романа — «пробуем, если что вырежем».

## D-STATS. Статистика отдыха (27.10.2026)
- `%AppData%\GigaRest\stats.json`: отрезки отдыха (начало — время сессии, конец — «Вернуться к работе») и запуски игр из «Играть». Храним год. Отдых дольше 3 суток не считаем (забыли вернуться).
- Время в Steam — его собственный подсчёт: `userdata\<id>\config\localconfig.vdf` → `apps` → `Playtime`, `Playtime2wks` (минуты). У других магазинов такого в открытом виде нет.
- Ничего не отправляется.

## D-SERVICES — свои сервисы и выбор браузера

- Список сайтов для «Смотреть» и «Слушать» — в настройках (`WebServices`), как свои игры. Пустой список (`null`) — первый запуск: YouTube и Яндекс Музыка, как было.
- Сервис открывается во встроенном WebView2 (свой профиль, вход запоминается) или в браузере: по умолчанию в Windows или в выбранном. Браузеры ищем среди ярлыков меню «Пуск», запускаем через `ArgumentList`.
- Сервисы с защищённым содержимым (Spotify, Apple Music, Кинопоиск, Okko, Иви, Netflix) по умолчанию — в браузере: WebView2 не поддерживает Widevine, а этим сайтам он нужен для воспроизведения. Пользователь может переключить на «здесь».
