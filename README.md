# GigaRest

**Режим отдыха для Windows 10/11.** Одна кнопка — и компьютер из рабочего становится домашним:

- рабочие программы вежливо закрываются, и освобождается память;
- уведомления затихают;
- на основном мониторе — спокойная сцена: пейзаж или своё видео с лёгким снегом, туманом или огоньками;
- на втором мониторе — до четырёх живых плиток с нужными окнами: мессенджер, браузер, музыка. Щёлкнул — окно открылось, свернул — снова плитки.

Вторая кнопка возвращает всё, как было.

> Проект в разработке.
>
> **Скачать свежую сборку:** [GigaRest-win-x64.zip](https://github.com/Luchano55/gigarest/releases/download/dev-build/GigaRest-win-x64.zip) — распаковать в обычную папку и запустить GigaRest.exe. Дальше программа обновляется сама.
