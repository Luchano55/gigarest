# Встроенные сцены

Пейзажи нарисованы программно, без чужих прав (CC0): `aurora`, `city`, `forest`, `mountains` — для макетов, `lake`, `winter`, `dunes` — скриптом `tools-src/scenes/make_scenes.py`. Позже их можно заменить настоящими пейзажами — своими или CC0.

Личные сцены Романа (обои и ролики из игр) в репозиторий не кладутся: они лежат у него в папке «Мои сцены» (по умолчанию «Изображения\GigaRest») и появляются в программе сами.
